# PinChat 2.0.0

Historical release for Minecraft **1.21.10**. The new automated gameplay tests have not been run on this version.

## Downloads and installation

| File | Loader | Required dependencies |
|---|---|---|
| [pinchat-mod-2.0.0.jar](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/2.0.0/pinchat-mod-2.0.0.jar) | Fabric (>=0.17.3) | Fabric API for your game version |

Requires Java 21. Install the matching loader, then put one PinChat JAR and its required dependencies in your game profile’s `mods` folder.

## Changes

- Implemented a new settings system with integration of several libraries (ClothConfig, YACL, Malilib, ModMenu)
- Added hotkey settings
- Expanded localization support

## Limitations

Controls and settings may differ from the current README. Do not assume current instructions apply to this historical version.

# PinChat 2.0.0

Исторический релиз для Minecraft **1.21.10**. Новые игровые автотесты на эту версию не запускались.

## Файлы и установка

| Файл | Загрузчик | Обязательные зависимости |
|---|---|---|
| [pinchat-mod-2.0.0.jar](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/2.0.0/pinchat-mod-2.0.0.jar) | Fabric (>=0.17.3) | Fabric API для версии игры |

Нужна Java 21. Установите соответствующий загрузчик, затем положите один JAR PinChat и обязательные зависимости в `mods` игрового профиля.

## Изменения

- Новая система настроек с интеграциями ClothConfig, YACL, MaLiLib и ModMenu.
- Добавлены настройки горячих клавиш.
- Расширена поддержка локализации.

## Ограничения

Управление и экран настроек могут отличаться от актуального README. Текущие инструкции не следует автоматически применять к этой исторической версии.
