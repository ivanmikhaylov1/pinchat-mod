## Installation

1. Install the loader for your game version and the Java version listed above.
2. Put the matching JAR in your game profile’s `mods` folder.
3. For Fabric and Quilt, add Fabric API for your exact Minecraft version. Forge and NeoForge need no additional mods.

Cloth Config, YACL, MaLiLib, and ModMenu are optional for this release.

## Controls

| Action | Keys / mouse |
|---|---|
| Pin or unpin a message | Right-click in normal chat |
| Create a group | Shift + right-click |
| Move / resize | Left-drag / drag ↘ |
| Collapse / rename / delete | Header / [R] / [X] |
| Chat mode with movement | U; close with U or Esc |
| Settings | P |

In multiplayer, `P` conflicts with Minecraft’s social menu; in 26.2, `O` opens the friends list. Rebind PinChat settings in Controls, for example to `F8`.

The default limit is 5 messages per group. Data is saved in `config/pinchat.json`.

## Validation of this published release

Builds, metadata checks, and client startup passed in [GitHub Actions](https://github.com/ivanmikhaylov1/pinchat-mod/actions/runs/36236974523). Those smoke tests checked startup, not in-world clicks.
The project owner previously confirmed a manual gameplay pass: pinning, groups, dragging, the mode toggle, and persistence. Quilt 1.21.11 was also checked manually.
The expanded automated gameplay system is being developed in the repository; its results are not retroactively attributed to this release.

## Checksums and limitations

[SHA256SUMS](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/3.1.0/SHA256SUMS) contains SHA-256 hashes for all 16 JARs. On Linux: `sha256sum --check SHA256SUMS`; on macOS: `shasum -a 256 --check SHA256SUMS` (download all listed files for a complete check).
Forge 26.x and Minecraft 26.3 are not supported.

## Установка

1. Установите загрузчик для вашей версии игры и Java из таблицы.

## Управление

| Действие | Клавиши / мышь |
|---|---|
| Закрепить или убрать сообщение | ПКМ в обычном чате |
| Создать группу | Shift + ПКМ |
| Переместить / изменить масштаб | Перетащить ЛКМ / потянуть за ↘ |
| Свернуть / переименовать / удалить | Заголовок / [R] / [X] |
| Режим чата с движением | U; закрыть U или Esc |
| Настройки | P |

В мультиплеере `P` конфликтует с социальным меню Minecraft; в 26.2 `O` занята списком друзей. В настройках управления переназначьте настройки PinChat, например на `F8`.

По умолчанию — 5 сообщений на группу. Данные сохраняются в `config/pinchat.json`.
