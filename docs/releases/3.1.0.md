## Установка

1. Установите загрузчик для вашей версии игры и Java из таблицы.
2. Положите подходящий JAR в `mods` игрового профиля.
3. Для Fabric и Quilt добавьте Fabric API для точной версии Minecraft. На Forge и NeoForge дополнительных модов не требуется.

Cloth Config, YACL, MaLiLib и ModMenu для этого релиза не обязательны.

## Управление

| Действие | Клавиши / мышь |
|---|---|
| Закрепить или убрать сообщение | ПКМ в обычном чате |
| Создать группу | Shift + ПКМ |
| Переместить / изменить масштаб | Перетащить ЛКМ / потянуть за ↘ |
| Свернуть / переименовать / удалить | Заголовок / [R] / [X] |
| Режим чата с движением | U; закрыть U или Esc |
| Настройки | P |

В мультиплеере `P` конфликтует с социальным меню Minecraft. В настройках управления переназначьте настройки PinChat, например на `O`.

По умолчанию — 5 сообщений на группу. Данные сохраняются в `config/pinchat.json`.

## Контрольные суммы и ограничения

[SHA256SUMS](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/3.1.0/SHA256SUMS) содержит SHA-256 всех 16 JAR. На Linux: `sha256sum --check SHA256SUMS`; на macOS: `shasum -a 256 --check SHA256SUMS` (скачайте все перечисленные файлы для полной проверки).
Forge 26.x и Minecraft 26.3 не поддерживаются.
