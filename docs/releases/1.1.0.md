# PinChat 1.1.0

Historical release for Minecraft **1.21.10**. The new automated gameplay tests have not been run on this version.

## Downloads and installation

| File | Loader | Required dependencies |
|---|---|---|
| [pinchat-mod-1.1.0.jar](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/1.1.0/pinchat-mod-1.1.0.jar) | Fabric (>=0.17.3) | Fabric API for your game version + MaLiLib |

Requires Java 21. Install the matching loader, then put one PinChat JAR and its required dependencies in your game profile’s `mods` folder.

## Changes

- **Customizable position**: Pinned messages can now be moved around the screen

## Limitations

**Metadata mismatch:** the original release title says 1.21.10, but the Fabric JAR declares `minecraft: ~1.21.1`. The loader may refuse to start on 1.21.10. The original binary is preserved; choose a newer matching release for a current installation.

Controls and settings may differ from the current README. Do not assume current instructions apply to this historical version.

# PinChat 1.1.0

Исторический релиз для Minecraft **1.21.10**. Новые игровые автотесты на эту версию не запускались.

## Файлы и установка

| Файл | Загрузчик | Обязательные зависимости |
|---|---|---|
| [pinchat-mod-1.1.0.jar](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/1.1.0/pinchat-mod-1.1.0.jar) | Fabric (>=0.17.3) | Fabric API для версии игры + MaLiLib |

Управление и экран настроек могут отличаться от актуального README. Текущие инструкции не следует автоматически применять к этой исторической версии.
