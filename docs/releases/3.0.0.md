# PinChat 3.0.0

Исторический релиз для Minecraft **1.21.11**. Новые игровые автотесты на эту версию не запускались.

## Файлы и установка

| Файл | Загрузчик | Обязательные зависимости |
|---|---|---|
| [pinchat-mod-fabric-3.0.0.jar](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/3.0.0/pinchat-mod-fabric-3.0.0.jar) | Fabric (>=0.18.1) | Fabric API для версии игры |
| [pinchat-mod-forge-3.0.0.jar](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/3.0.0/pinchat-mod-forge-3.0.0.jar) | Forge | Нет дополнительных модов |

Нужна Java 21. Установите соответствующий загрузчик, затем положите один JAR PinChat и обязательные зависимости в `mods` игрового профиля.

## Изменения

- Implement multi-platform support for Forge and Fabric
