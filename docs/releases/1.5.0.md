# PinChat 1.5.0

Исторический релиз для Minecraft **1.21.10**. Новые игровые автотесты на эту версию не запускались.

## Файлы и установка

| Файл | Загрузчик | Обязательные зависимости |
|---|---|---|
| [pinchat-mod-1.5.0.jar](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/1.5.0/pinchat-mod-1.5.0.jar) | Fabric (>=0.17.3) | Fabric API для версии игры + MaLiLib |

Нужна Java 21. Установите соответствующий загрузчик, затем положите один JAR PinChat и обязательные зависимости в `mods` игрового профиля.

## Изменения

- Add new group creation and interactive group management (drag, resize, rename, delete) on chat screen.

## Ограничения

Управление и экран настроек могут отличаться от актуального README. Текущие инструкции не следует автоматически применять к этой исторической версии.
