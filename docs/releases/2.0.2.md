# PinChat 2.0.2

Исторический релиз для Minecraft **1.21.11**. Новые игровые автотесты на эту версию не запускались.

## Файлы и установка

| Файл | Загрузчик | Обязательные зависимости |
|---|---|---|
| [pinchat-mod-2.0.2.jar](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/2.0.2/pinchat-mod-2.0.2.jar) | Fabric (>=0.18.1) | Fabric API для версии игры |

Нужна Java 21. Установите соответствующий загрузчик, затем положите один JAR PinChat и обязательные зависимости в `mods` игрового профиля.

## Изменения

- Update to Minecraft 1.21.11
