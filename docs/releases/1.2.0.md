# PinChat 1.2.0

Historical release for Minecraft **1.21.10**. The new automated gameplay tests have not been run on this version.

## Downloads and installation

| File | Loader | Required dependencies |
|---|---|---|
| [pinchat-mod-1.2.0.jar](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/1.2.0/pinchat-mod-1.2.0.jar) | Fabric (>=0.17.3) | Fabric API for your game version + MaLiLib |

Requires Java 21. Install the matching loader, then put one PinChat JAR and its required dependencies in your game profile’s `mods` folder.

## Changes

- Added visual resize handle to pinned messages.
- Enabled right-click to remove messages directly from the Config Screen.
- Integrated localization keys for new UI elements.

## Limitations

Controls and settings may differ from the current README. Do not assume current instructions apply to this historical version.

# PinChat 1.2.0

Исторический релиз для Minecraft **1.21.10**. Новые игровые автотесты на эту версию не запускались.

## Файлы и установка

| Файл | Загрузчик | Обязательные зависимости |
|---|---|---|
| [pinchat-mod-1.2.0.jar](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/1.2.0/pinchat-mod-1.2.0.jar) | Fabric (>=0.17.3) | Fabric API для версии игры + MaLiLib |

Нужна Java 21. Установите соответствующий загрузчик, затем положите один JAR PinChat и обязательные зависимости в `mods` игрового профиля.

## Изменения

- Добавлен видимый маркер изменения размера закреплённых сообщений.
- Сообщения можно удалять правой кнопкой мыши прямо на экране настроек.
- Добавлены ключи локализации новых элементов интерфейса.
