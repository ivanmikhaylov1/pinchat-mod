# PinChat 2.0.1

Historical release for Minecraft **1.21.11-pre1–pre5**. The new automated gameplay tests have not been run on this version.

## Downloads and installation

| File | Loader | Required dependencies |
|---|---|---|
| [pinchat-mod-2.0.1.jar](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/2.0.1/pinchat-mod-2.0.1.jar) | Fabric (>=0.18.1) | Fabric API for your game version |

Requires Java 21. Install the matching loader, then put one PinChat JAR and its required dependencies in your game profile’s `mods` folder.

## Changes

- Update to Minecraft 1.21.11-pre(1-5)

## Limitations

**Prerelease.** The JAR declares Minecraft as `1.21.11.x`, although the original release targets pre1–pre5. This range does not explicitly describe prerelease versions; the loader may reject it. For stable 1.21.11, choose a newer build.

Controls and settings may differ from the current README. Do not assume current instructions apply to this historical version.
