# PinChat 2.0.1

Исторический релиз для Minecraft **1.21.11-pre1–pre5**. Новые игровые автотесты на эту версию не запускались.

## Файлы и установка

| Файл | Загрузчик | Обязательные зависимости |
|---|---|---|
| [pinchat-mod-2.0.1.jar](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/2.0.1/pinchat-mod-2.0.1.jar) | Fabric (>=0.18.1) | Fabric API для версии игры |

Нужна Java 21. Установите соответствующий загрузчик, затем положите один JAR PinChat и обязательные зависимости в `mods` игрового профиля.

## Изменения

- Update to Minecraft 1.21.11-pre(1-5)

## Ограничения

**Предварительный релиз.** В JAR поле Minecraft задано как `1.21.11.x`, хотя исходный релиз заявляет pre1–pre5. Этот диапазон не описывает явно предварительные версии; возможен отказ загрузчика. Для стабильной 1.21.11 выбирайте более новую сборку.

Управление и экран настроек могут отличаться от актуального README. Текущие инструкции не следует автоматически применять к этой исторической версии.
