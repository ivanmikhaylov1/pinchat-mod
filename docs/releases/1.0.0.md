# PinChat 1.0.0

Исторический релиз для Minecraft **1.21.10**. Новые игровые автотесты на эту версию не запускались.

## Файлы и установка

| Файл | Загрузчик | Обязательные зависимости |
|---|---|---|
| [pinchat-mod-1.0.0.jar](https://github.com/ivanmikhaylov1/pinchat-mod/releases/download/1.0.0/pinchat-mod-1.0.0.jar) | Fabric (>=0.17.3) | Fabric API для версии игры + MaLiLib |

Нужна Java 21. Установите соответствующий загрузчик, затем положите один JAR PinChat и обязательные зависимости в `mods` игрового профиля.

## Изменения

**Full Changelog**: https://github.com/ivanmikhaylov1/pinchat-mod/commits/1.0.0

## Ограничения

**Расхождение метаданных:** название исходного релиза указывает 1.21.10, но Fabric JAR содержит `minecraft: ~1.21.1`. Загрузчик может отказать в запуске на 1.21.10. Бинарник сохранён без изменений; для актуальной установки выберите более новый подходящий релиз.

Управление и экран настроек могут отличаться от актуального README. Текущие инструкции не следует автоматически применять к этой исторической версии.
